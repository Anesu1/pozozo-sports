# POZOZO SPORTS — Authorised Molten & Mikasa Stock

> **Match balls, ordered by message.**  
> Official eCommerce platform for Pozozo Sports — Authorized stock of genuine Molten and Mikasa match and training balls (Basketball, Football, Netball, Accessories).

Built with **Next.js 14+ (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Key Features

- **51+ Genuine Match Models**:
  - **Basketball**: Molten BG5000 (Official FIBA Game Ball), BG4550, B33T5000 3x3 Libertria, GG7X, D3500, BC7R series, Mikasa CF700 & CF600 Leather, Street series (7, 6, 5).
  - **Football**: Mikasa FT550B Alumndo (FIFA Quality Pro), Molten F5A5000 Vantaggio (FIFA Pro), Super Kick Off, Match Thermal Bonded, and Junior trainers.
  - **Netball**: Mikasa FX5 Match, Mikasa Turbo SS-T League Series, Molten N5Y3500, Junior Size 4.
  - **Accessories**: Mikasa AG500 Digital Pressure Gauge with micro-bleed valve.
- **Direct 1-Click WhatsApp Ordering**: Instant single-item inquiry with pre-formatted product specifications.
- **Multi-Item Enquiry Drawer**: Add multiple balls across sports, adjust quantities, input delivery locations, and tap **"Send Order on WhatsApp"** or **"Send as Email"**.
- **Bulk & School Procurement**: Integrated quick-form for athletic directors and schools to request formal volume pro-forma invoices.
- **Interactive 3D Sphere Tilt**: Realistic physics-based ball rotation, dynamic floor shadows, and specular glare shader.
- **Responsive Across All Screens**: Tailored for 320px mobile phones up to 4K desktop screens.
- **Multi-Currency Support**: Live conversion for ZMW (K), USD ($), EUR (€), GBP (£), CAD (CA$), AUD (AU$), and JPY (¥).

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
